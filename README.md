Just a extension to the BetterF3 mod that adds a weather module

This Extension of the betterF3 mod Adds a weather module to the F3 menu. It supports up to 7 different languages and is customizable through the BetterF3 config. It also supports quilt make sure you use fabric api and cloth config api even if it says it doesn't support it.
